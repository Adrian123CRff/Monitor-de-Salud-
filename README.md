# Monitor-de-Salud-
Este proyecto esta basado en un monitor de salud de un sistema gestor de datos

## Requisitos para compilar

Solo necesitas **Java 21 o superior** instalado. No instales Maven aparte: el
proyecto trae su propio Maven Wrapper.

```bash
# Windows
.\mvnw.cmd test

# Mac / Linux
./mvnw test
```

La primera vez descarga Maven 3.9.16 dentro de `~/.m2/wrapper/` automáticamente.

Decisiones de arquitectura documentadas en `docs/adr/`. Diagramas en `docs/diagramas/`.
