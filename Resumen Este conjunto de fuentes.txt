Resumen: Este conjunto de fuentes detalla el diseño y la implementación de un monitor de salud para bases de datos Oracle, estructurado mediante un sistema de indicadores técnicos. El núcleo del proyecto consiste en recolectar datos específicos de tres áreas críticas: procesos, memoria y archivos, transformándolos en índices mediante consultas SQL avanzadas. Estos valores se comparan con umbrales y métricas definidos por expertos para determinar el estado operativo real del sistema, más allá de su simple disponibilidad. La herramienta utiliza ponderaciones matemáticas para generar un índice de salud global que se visualiza en un tablero de control o dashboard con alertas cromáticas. Este enfoque permite a los administradores realizar diagnósticos proactivos, identificar patrones de riesgo y aplicar controles correctivos antes de que ocurran fallos críticos. Además, se destaca la importancia de comprender la arquitectura del sistema gestor para interpretar correctamente variables como la contención de procesos o la presión en la memoria.
